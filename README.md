## / now · 最近在做

- **DSH 插件生态** — 给 DeepSeek Harness 写插件：供应链感知的自动更新器（只升 pnpm release-age 放行的版本，先快照、可回滚）、超长会话的离屏渲染优化、OmniRoute 模型管理面板；另外维护一个去噪的开源插件注册表 [awesome-dsh-plugins](https://github.com/publieople/awesome-dsh-plugins)。
- **AI 个人助手「舰队」** — 以 Hermes + OpenClaw 为骨架跨端编排（CLI / 飞书 / Telegram），沉淀 100+ Skills，cron 调度、健康检查与记忆维护全部自动化。
- **具身智能实验室 · 终端服务部** — 管理 4×A10 推理集群（Ollama / vLLM / ComfyUI），规划「终端基础 + 现代 Web 全栈」培训课程，并把经验沉淀成可交付的知识库。
- **技术写作** — 「通识分享企划」主理人，8 人团队、两周一篇深度输出；博客跑在 NotionNext + Vercel 上。
